# Brand artwork provenance

Extracted 2026-11-04 by `scripts/extract-brand-vectors.mjs` from the vector pages of
`WeAmaze_Visionary_Corporate_Identity_Manual_v1.0.pdf` (pages 7, 9, 12, 25).
Path data is byte-identical to the manual. Only the viewBox was set to the artwork bounds,
and colours were assigned per CI §05/§08/§10. Replace with the `02_LOGO_SYSTEM` masters when
they are supplied. Clear space (X = one quarter of the monogram height) is applied in layout,
not baked into these files.
